# LeetCode 556. 下一个更大元素 III

## 题目描述

给你一个正整数 `n` ，请你找出符合条件的最小整数，其由重新排列 `n` 的所有数字组成，并且值大于 `n` 。

如果不存在这样的整数，则返回 `-1` 。

同时要求返回的结果必须在 32 位整数范围内，如果超过 `INT_MAX` 也要返回 `-1` 。

---

## 题目思路

这道题本质上其实是：

> 求“下一个排列（Next Permutation）”

核心思想：

- 想办法让数字变得“大一点”
- 但又只能“大一点点”

所以：

1. 从右往左找“下降点”
2. 找右边刚好比它大的数字交换
3. 再把右边部分变成最小排列

---

# 一、寻找下降点

## 为什么从右往左找？

因为：

> 越靠右的位置变化，对整体数字影响越小

这样得到的结果才是“刚好大一点”。

---

## 如何找？

例如：

```cpp
12443322
```

从右往左观察：

```cpp
2 2 3 3 4 4
```

这一段一直是递减的。

直到：

```cpp
2 < 4
```

说明：

```cpp
2
```

这个位置还能变大。

---

## 对应代码

```cpp
int i = s.size() - 1;

while(i > 0 && s[i] <= s[i - 1])
{
    i--;
}
```

---

## 为什么是 `i-1` 才是真正的下降点？

因为循环停止时：

```cpp
s[i] > s[i-1]
```

真正满足：

```cpp
左边 < 右边
```

的是：

```cpp
s[i-1]
```

所以：

```cpp
i-1
```

才是真正要交换的位置。

---

# 二、在运行到第19个测试样例的时候之前会出现 `101 -> 101` 的错误

当时代码写的是：

```cpp
swap(s[i], s[j]);
```

但实际上：

```cpp
i
```

并不是下降点。

真正的下降点是：

```cpp
i-1
```

---

## 以 `101` 为例

### 原数字

```cpp
101
```

循环结束时：

```cpp
i = 1
```

因为：

```cpp
s[1] = '0'
s[0] = '1'
```

满足：

```cpp
0 <= 1
```

继续左移后停止。

---

### 真正下降点

应该是：

```cpp
i - 1 = 0
```

即：

```cpp
1
```

---

### 错误写法

```cpp
swap(s[i], s[j]);
```

变成：

```cpp
swap('0', '1')
```

最后结果还是：

```cpp
101
```

所以错误原因是：

> 把 `i` 当成了下降点，但实际上下降点是 `i-1`

---

# 三、寻找刚好比下降点大的数字

找到下降点后：

```cpp
s[i-1]
```

需要从右往左找到：

> 第一个比它大的数字

因为右边原本就是递减排列，所以：

> 从右往左找到的第一个更大的数，就是“刚好更大”的数。

---

## 对应代码

```cpp
int j = s.size() - 1;

while(j > 0 && s[j] <= s[i-1])
{
    j--;
}
```

---

# 四、交换

```cpp
swap(s[i-1], s[j]);
```

交换后：

- 数字一定变大
- 但右边部分仍然不是最小排列

---

# 五、为什么还要 reverse？

交换后：

```cpp
13443222
```

后半部分：

```cpp
443222
```

仍然是一个很大的排列。

但题目要求：

> “刚好大一点”

所以右边必须尽可能小。

---

## 关键性质

在寻找下降点时：

```cpp
下降点右边一定是递减排列
```

例如：

```cpp
443222
```

那么：

```cpp
reverse(...)
```

之后：

```cpp
222344
```

就会变成最小排列。

---

## 对应代码

```cpp
reverse(s.begin()+i,s.end());
```

注意：

这里是：

```cpp
+i
```

不是：

```cpp
+i-1
```

因为：

```cpp
i
```

本身就是下降点右边的起始位置。

---

# 六、完整代码

```cpp
class Solution {
public:
    int nextGreaterElement(int n) {

        string s = to_string(n);

        // 从右往左找下降点
        int i = s.size() - 1;

        while(i > 0 && s[i] <= s[i - 1])
        {
            i--;
        }

        // 找不到说明已经是最大排列
        if(i == 0)
        {
            return -1;
        }

        // 从右往左找第一个比下降点大的数字
        int j = s.size() - 1;

        while(j > 0 && s[j] <= s[i - 1])
        {
            j--;
        }

        // 交换
        swap(s[i - 1], s[j]);

        // 反转后半部分
        reverse(s.begin() + i, s.end());

        // 转回数字
        long long result = stoll(s);

        // 判断是否超过 int 范围
        if(result > INT_MAX)
        {
            return -1;
        }

        return result;
    }
};
```

---

# 七、时间复杂度

- 找下降点：`O(n)`
- 找交换位置：`O(n)`
- reverse：`O(n)`

总时间复杂度：

```cpp
O(n)
```

空间复杂度：

```cpp
O(1)
```

（不算字符串本身）

---

# 八、这题最重要的理解

这题最核心的其实只有一句话：

> “让数字变大一点，但只能大一点点”

所以：

- 尽量从右边修改
- 修改后右边尽量小

这就是：

```cpp
交换 + reverse
```

的本质。
